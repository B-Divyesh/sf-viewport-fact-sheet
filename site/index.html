Report fields

What the report records

Geometry

Border and content boxes, document offset, viewport position, centre delta, and visible-area ratio.

Clip and scroll chain

Relevant ancestors, overflow mode, scroll extent, current offset, and clipped edges.

Reachability

Computed visibility, viewport intersection, centre-point hit target, pointer events, and reason codes.

Style deltas

Position, insets, transform, z-index, box sizing, margins, borders, and padding.

How it works

Check one element in three steps

  1. 1

    Pick an element

    Open the toolbar popup or press Alt + Shift + V.

  2. 2

    Read the report

    Check the verdict, measurements, hit test, and ancestor chain.

  3. 3

    Export the JSON

    Copy or download a versioned report for a bug or test.

Playwright helper

Check reachability in a Playwright test

The helper accepts a selector or locator. It returns a report or throws reason codes.

Download single-file helperHelper and types (.zip)
checkout.spec.ts
import { getViewportFactSheet } from
  './viewport-fact-sheet-playwright.mjs';

const facts = await getViewportFactSheet(
  page,
  page.getByRole('button', { name: 'Pay now' })
);

expect(facts.verdict.reachable).toBe(true);
