Privacy policy · effective 6 September 2026

Privacy details for inspection reports

Viewport Fact Sheet inspects layout without collecting the contents of your page.

What the extension stores

The extension stores its latest report in local browser extension storage.

A report includes the page origin and path, title, selector, geometry, relevant styles, ancestor selectors, scroll positions, and hit-test result.

What a report excludes

Reports exclude form values, cookies, network bodies, page text, ARIA labels, screenshots, query strings, and URL fragments.

What this site receives

The extension has no analytics, remote API, account, or telemetry.

The static product site uses no cookies or third-party scripts.

Permissions

activeTab and scripting run the picker after you use the toolbar or keyboard shortcut.

storage keeps the latest report in the extension.

Delete a report

Choose “Clear” in the extension, clear its storage, or uninstall it.

Downloaded JSON remains wherever you save it.

Contact

For privacy questions, open an issue in the public source repository (external site).
